# Hi, I’m Ramadhan 👋

### Data Engineer · Building data pipelines & document-to-structured-data systems

I turn messy, real-world data (PDFs, scanned documents, transactional records) into clean, reliable, analysis-ready datasets. I build Python pipelines and CLI tools, model data in SQL, and use LLMs and RAG to extract and retrieve information from unstructured documents.

- 🔭 **Currently working on:** end-to-end batch and streaming data pipelines on GCP as part of the Data Engineering Zoomcamp
- 🌱 **Learning:** BigQuery, Airflow & Kestra, dbt, Spark, Kafka, Flink, Terraform
- 💬 **Ask me about:** Python data tooling, PDF/OCR extraction, SQL schema design, RAG with LlamaIndex

| Project | What it does | Stack |
